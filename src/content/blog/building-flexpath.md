# Building Flexpath

FlexPath is a mobile-first gig economy platform designed specifically for Bangladesh. It helps connect job seekers (like students, freelancers) with employers (such as small businesses or households) who need temporary, flexible workers for short-term tasks.

## The Problem

Finding reliable, short-term work or workers in Bangladesh can be a challenge. There wasn't a localized, secure, and user-friendly platform that handled identity verification and matching effectively.

## The Solution

Developed using Flutter (frontend) and Supabase (backend), FlexPath provides a tailored job matching experience. The app ensures trust and authenticity through NID (National ID) verification, real-time messaging, and role-based dashboards for different user types.

## Key Features

1. **Role-Based Access**: Separate panels for Job Seekers, Employers, and Admins.
2. **Secure Verification**: NID verification with admin approval to build trust.
3. **Real-Time Chat**: Instant communication using Supabase Realtime.
4. **Dynamic Job System**: Post, apply, and track jobs easily.

The platform is designed to empower local workers and provide businesses with flexible hiring solutions.
